## 任务 2：亲眼看见"有波前"和"没有波前"（本次重点）

这是本节的核心，务必做出来。

**在同一个一维空间里，用同一个初始脉冲，分别演化两个方程：**

**波动方程：**　∂²u/∂t² = v² ∂²u/∂x²
**扩散方程：**　∂u/∂t = D ∂²u/∂x²

**初值：** x = 0 处一个窄高斯脉冲（或方波），其余为零。

**做法建议**（你会写数值程序，用最笨的显式差分就行，不用追求精度）：
- 波动方程：`u[n+1] = 2u[n] - u[n-1] + (vΔt/Δx)²·(u[i+1] - 2u[i] + u[i-1])`
- 扩散方程：`u[n+1] = u[n] + DΔt/Δx²·(u[i+1] - 2u[i] + u[i-1])`
- 注意稳定性：波动要 vΔt/Δx ≤ 1；扩散要 DΔt/Δx² ≤ 0.5。**跑飞了就是踩了这个坑。**

**要看出并写下来的三件事：**

1. **波前**：波动解在某个位置之外**严格为零**吗？扩散解呢？
   → 建议用**对数纵轴**再看一遍，你会看到扩散解在"很远处"其实也不是零。
2. **形状**：随时间推移，两者的波形分别怎么变？
3. **时间反演**：把演化倒着跑（t → −t），哪个还是合法的解，哪个会炸？
   → 这一条直接对应"为什么反演是病态的"。

**强烈建议做成带时间滑块或播放按钮的动画**——这个现象是动态的，静态图看不出来。
