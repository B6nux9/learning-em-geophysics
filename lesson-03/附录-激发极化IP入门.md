# 附录 · 激发极化法（IP）入门

> 第 03 课学习者两轮深度追问的整理。起点是一个"跑题"的好奇：
> **"低阻矿体长时间通电会不会充满电荷？能不能先充电让它更好测？"**
> 这个问题从第一性原理重新发明了激发极化法（Induced Polarization, IP）——电法勘探三大支柱之一。
> 本附录把这两轮讨论整理成一份 IP 入门提纲。

---

## 一、缩写先拆（本课程铁律）

| 缩写 | 全称 | 中文 |
|---|---|---|
| **IP** | **I**nduced **P**olarization | 激发极化（法） |
| **SIP** | **S**pectral **I**nduced **P**olarization | 谱激电 |
| **PFE** | **P**ercent **F**requency **E**ffect | 频散率（频率域 IP 的观测量） |
| **SP** | **S**elf **P**otential | 自然电场法（同属传导类电法） |

---

## 二、物理起点：矿体会"充电"

给地下通电时，孔隙水里靠**离子**导电，金属矿物里靠**电子**导电。
在金属颗粒 / 孔隙水的**界面**上，离子进不了金属、电子进不了水，于是**离子在界面两侧堆积**，
形成"电荷屏障"（像电容器充电），产生反向的**超电压（overvoltage）**阻碍电流。

> **所以矿体确实会"充电"——这个现象叫极化（polarization）。**

两种机制：

| 机制 | 发生位置 | 敏感对象 |
|---|---|---|
| **电极极化** | 金属矿物 / 孔隙水界面 | 金属硫化物、石墨——找矿主力 |
| **薄膜极化** | 黏土颗粒的狭窄孔道 | 黏土（常是干扰，也可利用） |

**与第 01 课的联系：** 薄膜极化的来源就是黏土的**双电层 / 表面导电**——正是让阿尔奇公式失效的那个东西。
**同一个微观物理，在阿尔奇里是"误差源"，在 IP 里是"信号"。**

---

## 三、怎么测：充—放电，两种域

极化是**秒到分钟级的瞬态**，不能永久保存（不能今天充电、明天来测），
只能在一次测量内完成"充—测—放"。

**时间域 IP：**
```
通电几秒~几十秒（充电、极化建立）→ 突然断电
→ 电压不立刻归零，缓慢衰减（储存电荷在放电）
→ 测衰减曲线：衰减越慢、面积越大 → 极化越强 → 越可能是矿
```
观测量：**可充电性（chargeability, M）**，单位 mV/V 或 ms。

**频率域 IP：** 用两个频率各测一次电阻率，极化让低频 ρ 偏高、高频 ρ 偏低，
测频散率 PFE。**——又是时间域/频率域一枚硬币两面（第 05 课主题的又一例）。**

**关键：** 野外几乎总是"一次通电、两个结果"——稳定段电压给**电阻率**，
断电衰减段给**可充电性**。IP 数据几乎从不单独出现。

---

## 四、方法归类：它是"传导类电法"，不是感应电磁法

用第 01 课那张地图：电法勘探大伞下按"怎么送能量"分两家族。

| | 传导类（galvanic，接地） | 感应类（inductive，线圈） |
|---|---|---|
| 第 01 课叫 | "路线一：直接通电" | "路线二：电磁感应" |
| 成员 | 直流电阻率、**IP**、SP | TEM、MT、CSAMT、SOTEM |

> **IP 属于传导类，用接地电极工作，是直流电阻率的亲兄弟；与 TEM/MT 是两个平行分支。**

**但有个漂亮的越界（正是试题内容）：**
IP 是传导类现象，却会**串扰进感应类的 TEM** ——让 TEM 晚期道出现**负值**。
这就是试题综合题 4 的"**附加场效应**"之一。**你想探的涡流扩散信号里，混进了矿体充放电的极化信号，
两者符号可能相反。** 一个传导类现象，污染了一个感应类方法的数据。

---

## 五、正反演

**正演（双参数）：** 给定电阻率 ρ 和可充电性 M 两套分布，算地表视电阻率与视极化率。
巧妙做法：把电阻率写成**复数**（实部导电、虚部极化），IP 正演 = "复电阻率下的直流正演"。

> **对学习者研究的意义：会写实数电导率的正演，改成复数就能算 IP——不是另起炉灶，是同一台正演机器的延伸。**

**反演：** 通常分两步——先反演电阻率结构，再固定电阻率、把 IP 当微扰反演可充电性。
谱激电（SIP）更进一步，反演 Cole-Cole 参数（充电率、时间常数等），
用"充放电的节奏"反推矿物类型与颗粒大小。

---

## 六、反演病态吗？比电阻率更病态

继承直流电阻率的全部病态（扩散不可逆、深部分辨率崩塌、零空间），另加三重：

| 额外病态源 | 说明 |
|---|---|
| 信号本身极弱 | 极化率常只有百分之几、mV/V 量级，信噪比天生差 |
| 双参数耦合 | ρ 与 M 相互污染（故分步反演） |
| 电磁耦合污染 | 高频/大极距时感应效应伪装成极化，需先剥离 |

> **用第 02 课的语言：IP 反演的零空间比电阻率更大，需注入的先验更强。**
> 学习者当时追问的"能否补回信息、AI 效果如何、先验能否模拟"——原封不动适用于 IP，只是更严峻。

---

## 七、专治电阻率法的盲区（补上第 02 课发现的死穴）

第 02 课学习者问过"电磁法适合找高阻还是低阻"，结论是电磁法靠涡流、对低阻敏感，
但对一类目标无能为力——**浸染状硫化物矿**（金属颗粒稀疏散布、彼此不连通）：

| | 电阻率法 | IP |
|---|---|---|
| 浸染状硫化物 | ❌ 颗粒不连通、电流绕行、整体电阻率几乎不降 → **看不见** | ✅ 每颗颗粒都是充电界面，颗粒越多极化越强 → **看得清** |

> **IP 的杀手锏：它测的不是"导不导电"，是"有多少可极化的界面"。**
> 斑岩铜矿、浸染状金属矿普查，IP 是首选——因为这正是电阻率法的盲区。

---

## 八、联合反演：IP 的标准打法

**① 天生联合：电阻率 + IP（同一次测量）**
电阻率管"结构"（界面在哪）、IP 管"性质"（哪里可极化=可能是矿）；
两者叠合圈靶，大幅压缩单参数的多解性。

**② 跨方法联合，各补盲区：**

| 组合 | 为什么 |
|---|---|
| IP + 电阻率 | 浸染矿 vs 块状矿，组合能区分矿化类型 |
| IP + 磁法 | 硫化物常伴磁性矿物 |
| IP + 电磁感应(TEM/MT) | 感应找块状良导、IP 找浸染状，覆盖低阻的两种形态 |
| IP + 钻孔 | 硬约束、降病态 |

> **这就是第 26 课"多方法联合压缩零空间"思想的活案例——学习者在 IP 上提前见到了它。**

## 九、一张图收束

```
              电法勘探（大伞）
            ╱                ╲
    传导类（接地）          感应类（线圈）
    =第01课"路线一"          =第01课"路线二"
     ╱      ╲                    │
直流电阻率   IP激发极化          TEM/MT/CSAMT/SOTEM
 (ρ:结构)   (M:金属/极化)              │
    └──天生联合──┘                     │
          └───IP效应串扰进TEM晚期道(负值)──┘
                  =试题"附加场效应"
```

> **一句话：IP 是传导类电法，靠"充电—放电"（或频率域等价物）测可充电性 M，
> 专找电阻率法看不见的浸染状金属矿；有完整的双参数（复电阻率）正反演，反演比电阻率更病态；
> 标准解法是与电阻率、磁法、电磁感应联合，用"多信息压缩零空间"来治它的病。**
