# 附录 · 阿尔奇公式详解

> 第 01 课封版后的追问：每个参数什么意思、每个参数组合什么意思、整体什么意思。
> 这份附录把它彻底拆开。

---

## 零、先看清它的"身世"

**Gus Archie，1942 年，Shell 石油公司。** 他在实验室里量了大量**干净砂岩**岩心，
把测出来的数拟合成了两个经验关系。

**注意三件事：**

1. **它是经验公式**——不是从麦克斯韦方程推出来的，是从数据里拟合出来的；
2. **它诞生于石油测井**——目的是"从电阻率算出这层含多少油"，不是为地面电磁法设计的；
3. **它的实验对象是干净砂岩**——不含黏土。这决定了它的适用边界。

**完整形式：**

  **ρ_t = a · ρ_w · φ^(−m) · S_w^(−n)**

量纲自洽检查：ρ_t 与 ρ_w 同为 Ω·m，φ、S_w、a、m、n 全部无量纲。✓

---

## 一、它其实是两个公式缝起来的（结构性认识）

Archie 当年写的是**两个独立的关系**，对应**两组独立的实验**：

### 第一阿尔奇公式：地层因子

  **F = ρ₀ / ρ_w = a · φ^(−m)**

- ρ₀ = **100% 饱和水**时岩石的电阻率
- 实验做法：拿一批孔隙度不同的岩心，全部饱和同一种水，测 ρ₀，画 F–φ 双对数图，
  斜率就是 −m，截距给出 a。

### 第二阿尔奇公式：电阻率指数

  **I = ρ_t / ρ₀ = S_w^(−n)**

- ρ_t = **部分饱和**时的电阻率
- 实验做法：取一块岩心，逐步驱替出水、测不同 S_w 下的 ρ_t，画 I–S_w 双对数图，
  斜率就是 −n。

### 合并

  ρ_t = ρ₀ · I = (a · ρ_w · φ^(−m)) · S_w^(−n)

> **这就解释了"为什么有两个指数"：m 和 n 来自两个完全独立的实验，
> 一个管"岩石有多少路"，一个管"路上有多少水"。**

## 二、逐个参数

### ρ_w —— 孔隙水电阻率（公式的"原料"）

**含义：** 孔隙里那些水**本身**的电阻率。这是整个公式的基准值——岩石只是在这个基准上打折。

**由什么决定：**
- **矿化度（含盐量 TDS）**：离子越多越导电；
- **温度**：温度升高离子迁移率增大 → 更导电。

**温度校正（Arps 公式，摄氏）：**

  ρ_w(T₂) = ρ_w(T₁) · (T₁ + 21.5) / (T₂ + 21.5)

> **这在深部勘探里很关键：** 地温梯度约 30 ℃/km，
> 地表 20 ℃ 的水到 3 km 深就有 110 ℃，电阻率会降到原来的约 1/3。
> **换句话说，深部地层电阻率偏低，有一部分根本不是岩性变化，而是温度效应。**

**量级感：**

| 水的类型 | ρ_w（Ω·m） |
|---|---|
| 卤水 / 高矿化度地层水 | 0.01 – 0.1 |
| 海水 | 0.2 – 0.3 |
| 一般地下淡水 | 10 – 100 |
| 雨水 / 蒸馏水 | > 10³ |

### φ —— 孔隙度（"路有多宽"）

**含义：** 孔隙体积 / 岩石总体积。

**关键细节（常被忽略）：** 阿尔奇公式里的 φ 应该是**连通（有效）孔隙度**，而不是总孔隙度。

**为什么：** 封闭不连通的孔隙（火山岩的气孔、未连通的晶洞）里就算装满水也**不导电**，
因为电流进不去也出不来。把它们算进 φ，会高估导电能力。

→ 这是阿尔奇公式在**火山岩、致密碳酸盐岩**里失效的原因之一。

### m —— 胶结指数（"路有多曲折"）

**含义：** 描述孔隙网络的**连通性与曲折程度**。

**m 越大 → 孔隙越难走 → 同样孔隙度下电阻率越高。**

| 岩石类型 | m | 为什么 |
|---|---|---|
| **裂缝主导型** | ≈ 1.0 – 1.3 | 裂缝是**直通的**导电通道，几乎不绕路 |
| 松散未固结砂 | ≈ 1.3 – 1.5 | 颗粒间空隙宽敞连通 |
| 固结砂岩 | ≈ 1.8 – 2.0 | 胶结物堵住喉道，路径变曲折 |
| 碳酸盐岩（缝洞型） | ≈ 2.0 – 2.5+ | 孔洞大但连通差，"大房间小门" |

**名字的来历：** "胶结"指的是成岩过程中矿物质在孔隙喉道处沉淀（胶结），
把宽敞的通道堵成细窄弯曲的缝隙。**胶结越强 → m 越大。**

> **一句话记住 m：它是"孔隙空间迷宫化程度"的度量。**

### S_w —— 含水饱和度（"路上有多少水"）

**含义：** 孔隙体积中被水占据的比例。

**注意是"含水"不是"含油"：** S_w + S_o + S_g = 1。
油和气都是绝缘的，**只有水导电**，所以公式里只出现 S_w。

**含烃饱和度 = 1 − S_w**，这才是甲方真正想要的数。

### n —— 饱和度指数（"水断得多快"）

**含义：** 描述**水在孔隙中的分布形态**如何影响导电。典型 n ≈ 2，范围 1.5 – 2.5。

**这里有一个很深的物理，很多人只把 n 当拟合数字：**

> **n 的大小由岩石的润湿性（wettability）决定。**

| 润湿性 | 水的分布 | 后果 | n |
|---|---|---|---|
| **水湿（water-wet）** | 水贴着颗粒表面形成**连续水膜**，油在孔隙中央 | 即使 S_w 降到很低，水膜仍然连通、仍能导电 | **≈ 2**（正常） |
| **油湿（oil-wet）** | 油贴着颗粒表面，水被挤到孔隙中央成**孤立液滴** | S_w 稍降水路就断开 | **可达 3 – 10** |

> **所以 n 不是一个凑出来的数——它编码了微观尺度上流体怎么摆放。**
> 用错 n（比如对油湿储层套用 n=2）会严重**低估**含油饱和度。

### a —— 迂曲度系数 / 岩性系数（诚实地说：凑合因子）

**Archie 原始公式里 a = 1。** a 是后人为了改善拟合加进去的。

| 经验公式 | 表达式 | 适用 |
|---|---|---|
| Archie 原式 | F = φ^(−2) | 干净砂岩 |
| **Humble 公式** | F = 0.62 · φ^(−2.15) | 砂岩（工业常用） |
| Shell 公式 | F = 1.0 · φ^(−m)，m 随 φ 变 | 低孔碳酸盐岩 |

**必须知道的一点：a 和 m 是强相关的拟合参数。**

同一批实验数据，用 (a=1, m=2.0) 和 (a=0.62, m=2.15) 拟合，效果几乎一样好。
因为在双对数图上，a 管截距、m 管斜率，而数据点的孔隙度范围往往很窄，
**截距和斜率就分不开了**。

> **这是"参数耦合导致解不唯一"的一个最简单、最具体的例子。**
> 记住这个感觉——**第 24 课讲病态反演、第 26 课讲多解性时，你会看到同一件事的放大版。**
> 那时的"参数耦合"不是两个拟合系数，而是几千个网格单元的电阻率。

## 三、参数的组合分别是什么意思

### 组合 ①　F = a · φ^(−m) —— 地层因子（Formation Factor）

**含义：岩石骨架对水的导电能力打了多少折。**

- **无量纲**；
- **只由岩石几何决定，与水的性质完全无关**——这是它最有价值的性质；
- φ=0.25, m=2 → F = 16（导电能力降到水的 1/16）；
  φ=0.10 → F = 100；φ=0.05 → F = 400。

**F 的物理拆解（为什么指数是 2 而不是 1）：**

严格写成　**F = τ / φ**，其中 τ 是**曲折度（tortuosity）**。

| 效应 | 贡献 |
|---|---|
| **导电截面变小** | 一个 1/φ ——水只占 φ 的体积，电流管道截面只有 φ 那么大 |
| **路径变曲折** | 剩下的 φ^(1−m) = τ ——电流要绕着绝缘颗粒钻，实际路程远长于直线 |

m = 2 时 τ = 1/φ；φ = 0.25 → **τ = 4**，意思是电流的有效路程是直线距离的 4 倍。

> **这就是"两个效应各贡献一个 1/φ，所以是平方"的严格说法。**

### 组合 ②　ρ₀ = F · ρ_w = a · ρ_w · φ^(−m) —— 全饱和岩石电阻率

**含义："湿岩石"的基准电阻率。**

**这个组合最重要的价值是它把两件事分离开了：**

  ρ₀ ＝ （水的性质：ρ_w） × （岩石的几何：F）

**实际用途：**
- 知道 F（岩心标定或测井）+ 测到 ρ₀ → **反推 ρ_w，即地层水矿化度**；
- 知道 ρ_w（取水样）+ 测到 ρ₀ → **反推 F，进而反推孔隙度**。

### 组合 ③　I = S_w^(−n) —— 电阻率指数（Resistivity Index）

**含义：部分饱和相对全饱和，电阻率涨了几倍。**

  I = ρ_t / ρ₀

- **I = 1** → 纯水层，一滴烃都没有；
- **I 越大 → 含烃越多**。

**这是含油气性的直接指标**，把"岩石本身多导电"这个因素除掉了，只留下"流体换了多少"。

### 组合 ④　反解出 S_w —— **这才是工业上真正的用法**

  **S_w = [ a · ρ_w / ( φ^m · ρ_t ) ]^(1/n)**

**这个反解形式才是阿尔奇公式存在的理由。** 实际测井作业中：

| 需要的量 | 从哪来 |
|---|---|
| ρ_t | **电阻率测井** |
| φ | **孔隙度测井**（中子、密度、声波） |
| ρ_w | 水样分析、或自然电位（SP）测井反算 |
| a, m, n | **岩心实验室标定** |
| **↓ 算出** | |
| **S_w** | → **含烃饱和度 = 1 − S_w** → **储量计算** |

> **一句话：阿尔奇公式是一台翻译机，把"电阻率"翻译成"含油气饱和度"。**

## 四、换成电导率写，整个公式会突然变直观

电阻率形式里全是负指数，反直觉。**取倒数，用电导率写：**

  **σ_t = σ_w · (φ^m / a) · S_w^n**

**所有指数都变成正的了，而且每一项都是一个小于 1 的"折扣系数"**（因为 φ<1, S_w<1）：

| 项 | 角色 | 例（φ=0.25, S_w=0.3, m=n=2, a=1） |
|---|---|---|
| **σ_w** | 原料本身的导电本领 | 起点 |
| **φ^m / a** | **几何折扣**——路有多少、多曲折 | 0.25² = **0.0625**（打到 6.25%） |
| **S_w^n** | **填充折扣**——路上有多少是通的 | 0.30² = **0.09**（再打到 9%） |
| **总折扣** | 两次连乘 | 0.0625 × 0.09 = **0.005625** ≈ 1/178 |

  σ_t = σ_w / 178　⟺　ρ_t = 178 × ρ_w = 178 × 10 = **1 778 Ω·m** ✓

> **阿尔奇公式的本质就是两次连续打折：先被岩石几何打一次，再被含水程度打一次。**

## 五、整体在说什么——一个统一的物理图像

**把岩石想象成一团乱麻般的细管网络。**

- 管壁（骨架矿物）是**绝缘的**；
- 电流**只能**在装了咸水的管子里流；
- **ρ_w** = 管子里的水本身好不好导电；
- **φ** = 管子占了多大体积（路有多宽）；
- **m** = 管子有多弯、多细、连通得多差（路有多难走）；
- **S_w** = 管子里有多少是水、多少被油气堵住（路上有多少是通的）；
- **n** = 水一少，通路断得有多快（取决于水是贴壁膜状还是中央滴状）。

**三个层次的意义：**

| 层次 | 阿尔奇公式是什么 |
|---|---|
| **形式上** | 一个双幂律经验拟合公式 |
| **物理上** | **导电通路的几何 × 流体的填充程度** |
| **学科上** | **连接"物理场"与"地质意义"的桥梁** |

**第三层最重要。** 电磁法辛辛苦苦测出一张电阻率剖面，但甲方问的是
"这里含不含水、含不含油、含多少"。**没有岩石物理，地球物理就只是一堆彩色的电阻率图，
没有地质含义。** 阿尔奇公式是这类桥梁中最著名、最基础的一座。

## 六、适用边界——用之前必须问的五个问题

**这一节和公式本身同样重要。**

### ① 岩石"干净"吗？——最常见的失效原因

阿尔奇假设**导电全靠孔隙水**。但**黏土矿物表面带负电，会吸附阳离子形成双电层，
提供一条额外的导电通路（表面导电）**。

**后果链条：**

```
含黏土 → 有额外的表面导电 → 实测电阻率 比阿尔奇预测的 低
      → 反算出的 S_w 偏高 → 判断为"水层" → 漏掉油气层
```

> **这在石油工业里是要命的错误**——泥质砂岩油藏可能因此被判为干层放弃。

**修正模型：** Waxman–Smits 模型、Dual-Water 模型、Indonesia 公式，
都是在阿尔奇上加一个"黏土贡献项"。

### ② 孔隙连通吗？

封闭孔隙（火山岩气孔、孤立晶洞）不导电，应从 φ 中扣除。
否则会**高估导电能力**。

### ③ 还有水吗？

**S_w → 0 时 S_w^(−n) → ∞，公式给出无穷大电阻率。**
这在物理上是错的——干岩石的电阻率是有限的（10⁴–10⁶ Ω·m），由骨架和束缚水决定。

**干燥岩石的电阻率只能实测，不能用阿尔奇算。**

### ④ 有没有电子导体？

含**黄铁矿、磁黄铁矿、石墨**的岩石，导电靠自由电子，与孔隙水无关。
阿尔奇完全不适用——这也是它在**金属矿勘探**中基本用不上的原因。

### ⑤ 水够咸吗？

当 ρ_w 很高（淡水）时，孔隙水本身导电能力弱，**表面导电的相对贡献变大**，
阿尔奇的偏差随之增大。

> **通用教训（比公式本身更值得记住）：**
> **任何岩石物理经验公式都有适用边界。用它之前先问一句"它假设了什么"。**
> 这个习惯在后面读论文时会救你很多次——很多论文的结论错，
> 不是算错了，而是**在假设不成立的地方用了公式**。

## 七、往前看：这个公式的结构会反复出现

阿尔奇公式虽小，但它示范了本学科的四个通用模式：

| 模式 | 在阿尔奇里 | 后面在哪里重现 |
|---|---|---|
| **经验关系搭桥** | 电阻率 ↔ 含水饱和度 | 所有把物性翻译成地质意义的地方 |
| **参数强耦合** | a 与 m 分不开 | **第 24 课病态反演、第 26 课多解性** |
| **幂律 / 非线性放大** | S_w^(−2) | 电磁场的扩散、灵敏度随深度衰减 |
| **适用边界即失效条件** | 干净、连通、有水、非金属 | **每一个方法、每一个近似**（如第 02 课的准静态近似） |

**尤其是"参数强耦合"那一条。** 现在你看到的是两个拟合系数分不开；
到反演那里，你会看到几千个网格单元的电阻率彼此分不开——**那就是病态反演的本质。**
现在这个小例子里建立的直觉，到时候会直接用上。
