## 一、这节课教了什么

### 1. 一个尴尬的事实：仪器从来测不到电阻率

仪器测到的永远是**电压、电流、场**，不是电阻率：

| 方法 | 仪器实际测到的原始量 |
|---|---|
| 直流电法 | 电位差 ΔU 和供电电流 I |
| TEM | 接收线圈里的感应电动势（∂B/∂t 随时间的一串数） |
| MT / CSAMT | 正交的电场 E 和磁场 H（及比值、相位） |

电阻率是**地下介质的属性**，测不到属性本身，只能测到"**场对介质的响应**"。于是有了翻译问题：怎么把"我测到的响应"翻译成"地下的电阻率"？→ **视电阻率就是这道翻译的产物。**

### 2. 视电阻率的造法：假装 + 反解

三拍套路：
1. **假装地下均匀** → 只有均匀半空间下"观测量 ↔ 电阻率"才有干净的解析公式；
2. **把实测观测量代进公式**；
3. **反过来解出电阻率** → 就是 ρ_a。

以直流电法为例，均匀半空间理论给出 ρ = K·ΔU/I，反过来用即定义：

> **ρ_a ≡ K · ΔU / I**（"≡"是定义，不是测量，也不是真值近似）

三个符号：**ΔU**=电极间电位差（实测）、**I**=供电电流（实测）、**K**=装置系数（纯几何、已知，不含地下信息）。结构上：`ρ_a = K(几何) × ΔU/I(响应)`——**两个实测量 + 一个几何常数，就"变"出一个电阻率**，所以它是"造"出来的。

ρ_a 的物理含义：**"如果地下真是均匀的，要产生我实测的这个响应，它的电阻率看起来该是多少。"**（apparent = 表观的 / 看起来像的）

### 3. 视电阻率的四个脾气

- **① 不是任何一点的真电阻率**：是灵敏度"鼓包"范围内电阻率的加权平均。视电阻率剖面 ≠ 电阻率剖面，中间隔一道反演。
- **② 依赖装置和参数**：换装置/频率/时间，ρ_a 就变。它是"介质 + 装置 + 参数"的联合函数，不是介质纯属性。→ 给 ρ_a 曲线必须说清装置和参数。
- **③ 把无穷维地下压成可成图的数**：统一单位（Ω·m）、可比较、可成图（测深曲线 / 拟断面）、可作反演输入。**这是它存在的价值**。
- **④ 可能取荒谬值**：CSAMT 近场尾支 45° 上翘（假异常）、TEM 过渡区双解、IP 污染下晚期 ρ_a 为负。

### 4. 所有视电阻率是同一个套路

| 方法 | 视电阻率定义 | 靠什么测深 |
|---|---|---|
| 直流电法 | ρ_a = K·ΔU/I | 改电极距 |
| MT / CSAMT | 卡尼亚 ρ_a = (1/ωμ)·\|E/H\|² | 改频率 |
| TEM | 晚期 / 全区视电阻率（由 ∂B/∂t 反算） | 改观测时间 |

**共同套路：找一个"均匀半空间下 观测量↔电阻率"的干净公式，把它反过来用。** 方法差别只是塞进去的观测量不同（ΔU/I、E/H、∂B/∂t）。（Cagniard = 人名，法国地球物理学家；卡尼亚视电阻率 = 由波阻抗 |E/H| 反算的等效电阻率。）

## 二、课堂上实际展开的内容

### 延伸 1：为什么 ρ_a "允许荒谬"——两层因果要分开

学习者答"因为受仪器/环境影响、并非真实地质电阻，所以允许荒谬"。教练补上关键一层：

- **"受环境影响"解释的是它为什么偏离真值**；
- **"它是定义/计算量、不是物性"才解释它为什么被允许荒谬**——真电阻率被物理定律约束（不可能为负），而 ρ_a 只是个数字，不受物性约束。

> **荒谬的 ρ_a 不是地下的锅，是"假装均匀"这个假设在那里破产了。**

### 延伸 2：TEM"全区视电阻率"的实际操作（学习者主动追问）

学习者要求把"数值反解"落到地上，教练拆解了完整操作：

- **目标**：为每个时间道 t_i 算一个 ρ_a(t_i)。
- **核心把戏**：把"求 ρ_a"变成解方程 `V_i(观测) = F(ρ, t_i)`，其中 F 是**均匀半空间**的完整理论响应（**无早/晚期近似**）——即正演。
- **操作**：对每个时间道做**一维求根**（二分法/牛顿法），残差 g(ρ)=F(ρ,t_i)−V_i，求 g=0 的根即 ρ_a(t_i)。每评估一次 g 就调用一次半空间正演——这就是"反复调用正演"。
- **三点澄清**：
  1. 这**不是反演**——各时间道独立求"均匀半空间等效电阻率"，模型永远是单参数半空间；反演是一次性求整个分层/三维模型。
  2. 用的是**半空间正演**（快、常有解析式），不是三维大程序。
  3. 比晚期公式好在：用**完整 F** → 全时段成立、过渡区不再盲、双解消失；代价是得数值求根、反复调正演。
- **连回研究**：SOTEM 全区视电阻率算法正是这类工作。连"把一个数据点翻译成 ρ_a"都依赖正演。

## 五、本节一句话

> **仪器测的永远是电压、电流、场，不是电阻率。视电阻率 ρ_a 是把这些观测量"假装地下均匀、反解电阻率"翻译出来的等效值：它不是任何一点的真电阻率，而是装置有效范围内电阻率的加权平均，依赖装置与参数，可能取荒谬值。它的价值是把杂乱的原始观测量，变成统一、可比、可成图、可作反演输入的中转数据。**

## 六、留给第 05 课的问题

本课反复看到同一件事的三个版本：直流电法**改电极距**、MT/CSAMT**改频率**、TEM**看时间**——都能测深，本质都在调"看多深"。前几课也一直说"低频↔晚期""趋肤深度↔烟圈"。

> **频率域和时间域到底什么关系？为什么它们总能一一对应？一个发连续正弦、一个发脉冲看衰减，凭什么说是"同一件事"？**

答案是**傅里叶变换**——它会告诉你时/频域不是两种方法，是同一个物理的两种记账方式。

→ 第 05 课《时间域与频率域：一枚硬币的两面》（阶段一收官）
