> 以《电磁勘探理论与方法》（中国科学院大学，薛国强 / 雷达 / 王若）开卷试题为大纲踏板，
> 重排为一条从零到研究前沿的学习路径。
>
> **原则：物理图像是目的，数学是它的语言，代码是它的实验室。**

## 二、掌握等级体系（具体到本学科）

| 级 | 名称 | 能做什么 | 能力标志 |
|---|---|---|---|
| **L1** | Layman 门外汉 | 知道电磁勘探在解决什么问题，看得懂术语 | 给一篇论文，能说清它在解决什么问题、结论是什么 |
| **L2** | Beginner 入门 | 掌握核心 20%：扩散、趋肤深度、视电阻率、时频对应 | 拿到一条实测曲线，能定性判断地下大致结构 |
| **L3** | Intermediate 进阶 | 理解麦克斯韦→扩散方程、位函数、层状介质解 | **独立写出一维正演程序并验证正确** |
| **L4** | Advanced 高阶 ← **本课终点** | 掌握 2.5D/3D 数值正演、反演与正则化、噪声处理、观测系统设计 | **实现或改造 2.5D/3D 正演，跑通反演，能论证方案设计** |
| **L5** | Expert 专家 | 深入方法的底层假设与适用边界，能评价新方法、提出创新 | 读前沿论文能指出其隐含假设与局限，能提出自己的研究方向 |

> 课程主干走到 **L4**；第六阶段是通往 L5 的引桥，博士期间自然延伸。

## 三、二八原则：先攻这 4 件事

覆盖 80% 场景的核心 20%，就是下面四条。**拿下它们，卷子上一大半题目的物理内核就通了。**

1. **电磁场在导电大地中是"扩散"，不是"传播"**
   —— 整个学科的第一性原理。趋肤深度、烟圈、晚期道、分辨率随深度下降、反演病态，全部由此长出。
2. **趋肤深度 δ ≈ 503√(ρ/f)**
   —— 一个公式串起频率、电阻率与探测深度，是所有方法设计的标尺。
3. **视电阻率**
   —— 把"观测到的电压/电场/磁场"翻译成"地质语言"的通用桥梁。
4. **时间域与频率域是同一件事的两种看法**
   —— 理解 TEM 与 CSAMT/MT 之间关系的钥匙。

第一阶段（第 1–5 课）就是专门拿下这四条的。

## 五、每节课的固定节奏

1. **讲授** → 当场写入 `notes.md`
2. **布置作业** → 当场建立 `homework/`
3. **出 quiz** → 当场写入 `quiz.md`，作答后补上判分与反馈
4. **封版确认**（内容讲完 + 作业与 quiz 已反馈 + 你确认没有卡点）
5. **产出 `summary.pdf`** —— 基于讲义与真实对话，反映"这节课到底发生了什么"
6. **git commit + 更新 `PROGRESS.md`**

> **节奏归你掌握。** 一节课结束后我会停下等你开口，不会自动往下推。
> 你想在某个点上多停留、多提问，随时可以——那不是拖延，那是学习本身。
